# Asad Memon - Architectural Portfolio

![Portfolio Preview](images/asad.jpg)

A modern, interactive portfolio website showcasing architectural projects and design work by Asad Memon, an architecture student at Parul Institute, Vadodara.

## 🌟 Overview

This portfolio features a curated collection of architectural designs, including institutional projects, residential designs, heritage documentation, and competition entries. The site combines clean aesthetics with interactive elements to present work in an engaging manner.

## 🎯 Key Features

- **Responsive Design**: Optimized for desktop and mobile viewing
- **Dark/Light Mode Toggle**: Customizable viewing experience
- **Interactive Project Gallery**: Detailed project modals with specifications and galleries
- **Smooth Animations**: Custom cursor effects and scroll-based reveals
- **Three.js Background**: Dynamic architectural wireframe grid animation
- **Professional Typography**: Custom font combinations for enhanced readability

## 🏗️ Projects Featured

1. **The Flow Forum** (2025) - University campus design with organic circular modules
2. **Bandhani घर** (2024) - Workshop design embracing arc symbolism for traditional craft
3. **Luminous Veil House** (2025) - Compact residential design with central courtyard
4. **Sukoongruh** (2024) - Tiny house competition entry on shoreline setting
5. **Architectural Manifestations of a Culture in Transition** (2025) - COA Heritage Documentation of Parsi dwellings
6. **Freelancing Projects** (2025-26) - Architectural design and visualization work

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Custom properties, animations, and responsive design
- **JavaScript (ES6+)** - Interactive functionality and DOM manipulation
- **Three.js** - 3D background animations
- **Google Fonts** - Typography (Cormorant Garamond, Space Mono, Syne)

## 🚀 How to View

Since this is a static website, you can view it in several ways:

### Option 1: Direct File Opening
1. Download or clone the repository
2. Open `index.html` in any modern web browser

### Option 2: Local Server (Recommended)
For the best experience with all features:
```bash
# Using Python (if installed)
python -m http.server 8000

# Or using Node.js
npx serve .
```
